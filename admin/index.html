Quick Tips
  • Codes are redeemable in-app on the pricing screen ("Have an access code from your attorney?")
  • Expiry controls when users can redeem the code — not when their access ends
  • Once deactivated, a code cannot be re-activated
  • Custom codes are automatically uppercased and stripped of special characters
  • Set Max Redemptions to a large number (e.g. 9999) for effectively unlimited use

Deactivate Code?
